# desafio-frontend-backend
Esse projeto foi proposto pelo professor Diego França dos Santos, com o objetivo de instruir os alunos à aplicar os conhecimentos adquiridos.

Sobre o projeto

O projeto consiste na criação de uma API utilizando Express e de um frontend que utiliza Fetch para consumir os dados disponibilizados pela API.

A API retorna informações de livros, como nome, categoria e preço, e o frontend apresenta esses dados em cards na página.

Tecnologias utilizadas
HTML
CSS
JavaScript
Node.js
Express
Fetch API
